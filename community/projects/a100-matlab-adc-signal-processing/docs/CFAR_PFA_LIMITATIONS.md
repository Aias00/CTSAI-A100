# CFAR 的名义参数与实际虚警率

`opts.cfar.pfa` 是参考模型下的名义门限参数，不能直接作为最终检测器的实测虚警率。
输出 `cfarResult.nominal_pfa` 记录该输入，`pfa_calibrated=false` 明确标识尚未校准。
本 PR 不改变门限，也不将已有 CSV/图片重新解释为校准结果。

- CA 的 `N*(pfa^(-1/N)-1)` 假设 CUT 和训练样本为独立同分布指数功率。
- OS 的系数求解同样基于单视线指数噪声。
- GOCA/SOCA 对四个扇区均值取极值后仍使用 CA 系数。极值分布与单个均值不同，
  且各扇区样本数可能不同；该实现是近似门限。
- VI 根据当前训练数据选择扇区，其选择事件改变统计分布，不能只按选中样本数校准。
- 本链路在 Doppler FFT 后平均多个 RX 功率；独立通道时噪声更接近 Gamma 分布，
  通道相关时还会变化。Hann 窗及 SVD 也改变单元相关性和噪声统计。
- 峰值筛选、SNR 筛选和零速排除进一步改变最终报告的虚警口径。

## 可复现的诊断

在项目目录执行：

```matlab
addpath('tests');
report = run_cfar_pfa_diagnostics(200000);
```

固定随机种子，直接在 CUT/训练统计层生成独立指数噪声，对比 CA、GOCA、SOCA，
输出每个 CUT 的告警率及 Wilson 95% 区间，同时验证 CA 的参考公式。
该实验故意不经过 FFT、SVD、多通道平均或峰值筛选，不能代替完整处理链标定，
不包含 VI 的自适应分支标定。返回结构记录算法、样本数、命中数、名义值和置信区间。

## 仍需完成的标定

针对完整处理链和每种算法，使用独立的校准集/验证集，覆盖通道相关性、窗函数、
SVD、扇区参数和不同噪声/杂波模型；记录有效 CUT 的分母、最终候选数、置信区间，
并在足够多样本下校验 1e-4 尾部概率。经验系数只能用于标定覆盖的配置。
合成噪声实验不能替代真实场景有标签的虚警与漏检评估。

相关独立多通道 CA 标定研究见上游 PR #86；其系数不能直接套到 GOCA/SOCA/VI。
